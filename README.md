# 🌍 BookIt — Experiences & Slots

A fullstack travel booking platform where users can explore experiences, select available slots, apply promo codes, and complete bookings — built using **React + TypeScript + TailwindCSS** (frontend) and **Node.js + Express + MongoDB** (backend).

## 🧩 Project Overview

**BookIt** allows users to:
- Browse curated travel experiences (with images and pricing)
- View experience details with date/time slot availability
- Select slot & quantity and proceed to checkout
- Apply promo codes
- Confirm booking and view a success page with reference ID

Full user flow:
> Home → Experience Details → Checkout → Booking Confirmation
